# FluffelDrone 

![Fusion](https://halflife.hackclub-assets.com/hackclub-half-life/sessions/4fbHVD2HJmUknZX98YuazYMMhIgWKpgb/088c2f7abf212ee6e46e57684c220eedd7e68d5faa39fe857cf0ac2349648325.png)

FluffelDrone is part of the project **FluffelBot**. The goal is to build a small, low-cost drone that can be controlled over Wi-Fi (MQTT).

## What is **FluffelDrone** and why did I made it
FluffelDrone is a small, 3d-printed and low-cost drone. It has four motors and is controlled by an ESP32-CAM. You can control it over Wi-Fi with MQTT and there will be a camera livestream.
I designed it for a school project (**FluffelBot**). FluffelBot will be a cool robot. He can drive, grab things, control the FluffelDrone, give treats and many more things!

## Features
- Camera Livestream
- Control via MQTT
- Fly with 4 motors in any direction
